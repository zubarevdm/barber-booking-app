# BLADE — приложение для записи в барбершоп

Кросс-платформенное мобильное приложение (iOS + Android) для записи в сеть барбершопов
**BLADE** (вымышленный демо-бренд). Сделано на **React Native (Expo Router)**. Визуальный
стиль — брутальный монохром: чёрный фон, белые акценты, плотная типографика с разрядкой
и тонкий золотой акцент.

> Демонстрационный проект: бренд, филиалы, барберы и цены — вымышленные, любые
> совпадения случайны. Запись сохраняется локально на устройстве (AsyncStorage) —
> без бэкенда и реальной оплаты.

## Возможности

- **Главная** — герой-баннер, популярные услуги, мастера, программа лояльности.
- **Услуги и цены** — каталог с фильтром по категориям и реальным прайсом (по мотивам сайта).
- **Филиалы** — список барбершопов по городам, звонок и открытие на карте.
- **Профиль** — предстоящие записи, история, прогресс лояльности, отмена записи.
- **Флоу записи** в 4 шага: услуга → мастер → филиал/дата/время → подтверждение.
  - Цена пересчитывается под грейд мастера.
  - Слоты времени генерируются на 14 дней, занятые помечаются.

## Запуск

Нужен установленный [Node.js](https://nodejs.org/) 18+.

```bash
npm install
npm start
```

Дальше:
- **На телефоне** — установите приложение **Expo Go** (App Store / Google Play) и
  отсканируйте QR-код из терминала.
- **Android-эмулятор** — нажмите `a` в терминале (нужен установленный Android Studio).
- **iOS-симулятор** (только macOS) — нажмите `i` (нужен Xcode).

## Стек

| Слой | Решение |
|------|---------|
| UI / рантайм | React Native 0.76 + Expo SDK 52 |
| Навигация | expo-router (файловая, типизированные маршруты) |
| Состояние | React Context + AsyncStorage |
| Иконки | @expo/vector-icons (Ionicons) |
| Язык | TypeScript (strict) |

## Структура

```
app/                     # экраны (expo-router)
  _layout.tsx            # корневой Stack + провайдеры
  (tabs)/                # нижние табы
    index.tsx            # Главная
    services.tsx         # Услуги и цены
    locations.tsx        # Филиалы
    profile.tsx          # Профиль / мои записи
  booking/               # пошаговый флоу записи
    service.tsx          # шаг 1 — услуга
    barber.tsx           # шаг 2 — мастер
    time.tsx             # шаг 3 — филиал, дата, время
    confirm.tsx          # шаг 4 — подтверждение
    success.tsx          # экран успеха
src/
  theme.ts               # цвета, типографика, отступы
  components/             # переиспользуемый UI
  data/                  # моковые данные (услуги, мастера, филиалы)
  store/                 # BookingContext (черновик + записи)
  utils/                 # даты, слоты, форматирование
```

## Что подключить для продакшена

- Реальный бэкенд (Firebase / Supabase / собственный API) вместо моков.
- Авторизацию по номеру телефона (SMS).
- Реальное расписание мастеров и онлайн-оплату.
- Push-уведомления (expo-notifications) для напоминаний о визите.
- Фирменные иконку и сплэш-скрин в `assets/` (сейчас используются дефолтные Expo).
